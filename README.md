# MapCraft

Фанатская некоммерческая глобальная стратегия в сеттинге Майнкрафта. Основа — EU4 (карта провинций, страны,
дипломатия, войны). У Victoria 2 берутся POPs и экономика: товары, RGO, заводы. Карта будет воксельной (блоки), UI и
звуки — Майнкрафта. Отдельная игра для Windows (`mapcraft.exe`) плюс редактор провинций `mapcraft_editor.exe`.

Проект вырос из Tamriel Universalis (EU4-подобная стратегия по Тамриэлю, SKSE-плагин для Скайрима). Всё, что было
связано со Скайримом и TES, и весь «вид» гладкой карты вырезаны. Что осталось и почему — docs/HANDOFF.md.

## Состояние
- **Карта**: плоская заглушка. Пиксели закрашены по классу (море, суша, озеро, пустошь), поверх — заливки режимов
  карты, реки, границы провинций и стран как в EU4, названия по алгоритму EU4. Вокселей пока нет (docs/RENDER.md).
- **Игра**: экран выбора страны → Play → камера летит к столице. Дневной тик с календарём-заглушкой, пятью скоростями и
  паузой; пока тик меняет только дату (docs/GAMEDATA.md). UI отладочный (Dear ImGui).
- **Исходники карты переходят на сетку блоков.** Есть карта высот из Azgaar и из неё `land.png`; остальные
  рисунки пользователь ещё не нарисовал, а инструменты после `land.png` ещё ждут старую пиксельную карту
  (docs/HANDOFF.md, «Порядок работ над картой»). Пока нет `build/map/world.mcmap`, `mapcraft.exe` не запустится.
- **Игровых данных нет**: в `data/` только заголовки CSV.

## Код (`code/`, C++23, MSVC + CMake/Ninja + vcpkg)
Нужны MSVC Build Tools (`build.cmd` находит компилятор через vswhere) и переменная окружения `VCPKG_ROOT` (путь к
vcpkg); триплет `x64-windows-static`, из зависимостей только `imgui`.
```bash
code/build.cmd                                  # сборка всего в code/build/release
code/build/release/mapcraft.exe                 # игра
code/build/release/mapcraft_editor.exe          # редактор провинций, пишет data/setup
code/build/release/mapcraft_editor.exe --check  # только проверить data/ (ошибки в mapcraft_editor.log); других флагов у exe нет
```
| Папка | Что |
|---|---|
| `src/core/` | ввод, камера, загрузка `world.mcmap`, CSV, раскладка названий EU4 (`labels.cpp`), лог; без платформы и без игры |
| `src/render/` | D3D11: карта (плоскость, реки, границы, названия) |
| `src/game/` | игра без UI и D3D. `GameData` = `Content` (неизменяемые справочники, все строки) + `WorldState` (SoA-столбцы). `World` владеет ими и отдаёт наружу только `const`. `Session` — выбор страны, потом игрок и темп времени (`pace.h`). `calendar.h` — календарь. `countries.cpp` — запросы по странам |
| `src/ui/` | интерфейс игры на Dear ImGui (ввод из `mc::Input`): слой ImGui, флаги, виджеты, экраны `screens/` |
| `src/app/` | `App` — карта: камера, режимы карты (`map_modes.cpp`), пикинг, отрисовка. `bindings.cpp` — все привязки клавиш. `Shell` — игра для хоста, связывает `World`, `App`, `Session` и `GameUi` |
| `src/host/win32/` | хост `mapcraft.exe`: окно, swap chain, ввод |
| `src/editor/` | `mapcraft_editor`: `App` + свой `GameData` (правит старт, а не живой мир) + панели ImGui |

Правила слоёв:
- `game/` не знает UI и D3D; `WorldState` меняют только правила самого `World`.
- Экраны `ui/` только читают состояние и возвращают `UiCommands`; выполняет их `Shell`.
- `App` и `Camera` не знают клавиш: им приходят намерения (`CameraInput`), коды клавиш есть только в
  `app/bindings.cpp`.
- В `Shell` объект `World` объявлен раньше `App`, потому что карта держит указатель на его данные.

Известные долги:
- `mapcraft.exe` и `mapcraft_editor.exe` дублируют Win32-код окна и ввода.
- `edit_provinces.py` при перенумерации не переписывает `data/setup/provinces.csv` (раздел «Правка провинций»).

## Управление
**Карта:**
- колесо — зум к курсору; вблизи камера наклоняется;
- правая или средняя кнопка — тащить карту;
- WASD или стрелки — двигать, Home — вся карта;
- 1–4 — рельеф, политика, провинции, регионы.

**Игра:**
- клик по стране — справа сверху её сводка; справа снизу кнопка Play;
- после Play камера летит к столице; у страны без столицы — к самой развитой провинции;
- время: игра стартует на паузе, скорость 3. Space — пауза, +/− (и на нумпаде) — скорость 1–5; то же кнопками
  справа сверху;
- Esc — выход.

Логи `mapcraft.log` и `mapcraft_editor.log` лежат рядом с exe.

**Редактор:**
- выделение:
  - клик — выбрать провинцию;
  - Ctrl+клик — добавить или убрать;
  - Shift+клик или Shift+протяжка — добавить;
  - Alt+клик — весь регион;
  - Esc — снять выделение;
- «Provinces» меняет поля всех выделенных провинций: владелец (по умолчанию он же контролёр и получает кор),
  контролёр, коры, terrain, культура, религия, development, товар, узел, центр торговли, «столица владельца»;
- «Countries» — столица, основная культура, государственная религия, выделить провинции страны;
- «Map mode» — все 10 режимов;
- Save — Ctrl+S, Undo/Redo — Ctrl+Z / Ctrl+Y; «Next unfilled» — к следующей незаполненной провинции.

## Карта: исходники (лежат в корне)
Карта — сетка 1152×576 блоков (`WIDTH`, `HEIGHT` в `tools/mapgen/validate_land.py`). Блок — 4×4 пикселя карты
(4608×2304) и куб: ступень по высоте равна ширине блока. Рисунки пользователя — 1 пиксель = 1 блок.

| Файл | Что |
|---|---|
| `heightmap.png` | экспорт Azgaar's Fantasy Map Generator, 4608×2304: в Azgaar Map size и Viewport size 1152×576, вся карта в окне без сдвига, PNG-экспорт ×4, включён только слой высот в монохромной схеме. Единственный источник истины для берегов и высот |
| `land.png` | делает `heightmap.py`, 1152×576: `#000000` море, `#FFFFFF` суша, `#0080FF` озеро (меньше 156 блоков — декоративное: вода на вид, суша в игре). Руками не правится: правка — в Azgaar |

Ниже — исходники в формате старой пиксельной карты (4608×3072, пустошь `#808080` в `land.png`); они переходят на
сетку блоков по docs/HANDOFF.md.

| Файл | Что |
|---|---|
| `regions.png` + `regions.csv` | регионы: цвет на пиксель; `regions.csv` — id, color, name, parent (земля: регион верхнего уровня), type, provinces (сколько провинций: × `MULTIPLIER` в `generate_provinces.py`) и служебные колонки |
| `seeds.png` | необязателен: красные точки — закреплённые центры провинций |
| `rivers.png` | необязателен: реки, соглашение EU4 `rivers.bmp` — линии 1 px, `#00FF00` исток, `#FF0000` последний пиксель притока, синие — ширина от `#00E1FF` (узкая) до `#000064` (широкая) |
| `provinces.png/.csv`, `adjacency.csv` | генерируются `generate_provinces.py`, потом **замораживаются**: правки только через `edit_provinces.py`. Имена провинций — колонка `name` в `provinces.csv`, её заполняет пользователь |
| `Cinzel-VariableFont_wght.ttf` | шрифт названий на карте (`tools/fonts/mapfont.py`); замена шрифта — решение пользователя |

Бинарники (png, ttf, npz…) в репозиторий не идут.

## Карта: сборка (`tools/`, Python 3.14 + numpy/scipy/scikit-image/Pillow/numba/fontTools)
Из карты высот:
```bash
python tools/mapgen/heightmap.py                              # heightmap.png -> land.png + build/heightmap/steps.png (ступени)
python tools/mapgen/validate_land.py land.png                 # проверка палитры, связности, тонких мест
```
**Импорт высот** (`heightmap.py`). Azgaar рисует высоту `h` (суша 20–100) серым `d3.interpolateGreys(1 − h/100)`;
импорт обращает эту кривую (точность ±1). Суша — серый от 63; всё темнее — полосы глубин моря и сглаживание берега.
Блок — суша, если суша в большинстве его 4×4 пикселей; его ступень = round((среднее h − 20) / 2.5), так что h = 100 —
32-я ступень (выше Azgaar не поднимает: там плато). Вода, не доходящая до края карты, — озеро. Квадрат 2×2, где суша
касается только по диагонали, разрешается сменой блока с самым близким к ничьей голосованием. Импорт отказывается
работать, если размер не тот, картинка не серая или серый суши не ложится на схему (поменяли оформление слоя).
`read_blocks()` отдаёт классы и ступени блоков остальным инструментам; промежуточного файла с высотами нет.

Старая пиксельная карта, один раз, из исходных рисунков:
```bash
python tools/mapgen/generate_provinces.py                     # land + regions (+ seeds) -> build/provinces: provinces.png/.csv, adjacency.csv
```
Результат `generate_provinces.py` переносится в корень руками, после этого провинции заморожены.

Каждый раз, когда что-то изменилось:
```bash
python tools/mapbake/rivers.py                                # проверка rivers.png (ничего не пишет)
python tools/fonts/mapfont.py                                 # шрифт названий: метрики Mapfont.fnt + SDF
python tools/labels/provinces.py                              # названия провинций (до positions.py: города их обходят)
python tools/mapbake/positions.py                             # точки городов, армий, подписей, портов -> positions.csv
python tools/mapbake/bake.py                                  # build/map/world.mcmap (docs/MAPFORMAT.md)
```
`tools/labels/` нужен `C:\Dev\Projects\eu4\archeologyEU4\Labels\LabelPython` (путь в `tools/labels/reference.py`).

**Порты.** Порт есть у каждой сухопутной провинции, граничащей с морской (озёра не считаются): точка в `PORT_OUT` px от
берега над морем, напротив ближайшего к городу места берега.

**Правка провинций:**
```bash
python tools/mapgen/edit_provinces.py split-islands | give-island X Y NAME | sync-lakes
```
`sync-lakes`: озеро, у которого в `land.png` стало меньше воды, оставляет себе самый большой кусок; высохшее дно делят
соседи; озеро без воды удаляется, номера после него сдвигаются. **Внимание:** `edit_provinces.py` пока не трогает
`data/setup/provinces.csv`. После перенумерации старые id в нём указывают не на те провинции. Это долг: исправить до
первой правки карты с заполненными данными. Потом `positions.py` → `bake.py`.

## Игровые данные (`data/`)
CSV: определения в `data/common/` и старт в `data/setup/`. Формат, проверки и раскладка в памяти —
docs/GAMEDATA.md. Данные заполняет пользователь в `mapcraft_editor`.

## Ассеты Майнкрафта
Текстуры, шрифт, звуки и модели Майнкрафта **не распространяются** и в репозиторий не попадают: игра будет читать их
из установленного у игрока Майнкрафта (jar версии и индекс ассетов в `.minecraft`). Пока этого загрузчика нет.
