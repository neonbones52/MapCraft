# Интерфейс

**Сейчас** UI — стоковый Dear ImGui (шрифт Segoe UI, масштаб шагом 1/8), отладочный. Ниже — решение пользователя, по
которому он переделывается в срезе UI Майнкрафта (docs/ROADMAP.md); пока не воплощено.

## UI Майнкрафта на основе Dear ImGui
- ImGui даёт ввод, ID, обрезку, прокрутку, `ListClipper`, тултипы, поля ввода и таблицы. Поверх — свои виджеты
  Майнкрафта через `imgui_internal` (`ButtonBehavior` + `ImDrawList`).
- 9-slice спрайтов `gui/sprites/...` по `.mcmeta`; растровый шрифт `font/default.json` (есть кириллица); тень текста —
  сдвиг на 1 px, цвет × 0.25; точечная выборка; целочисленный GUI scale.
- Панели — процедурно: серый `#C6C6C6`, светлый край сверху-слева, тень `#555555`, чёрный контур.
- Иконки товаров — предметы Майнкрафта, зданий — блоки; флаги стран — баннеры с узорами (данные, не арт).
- Графики — ImPlot; маленькие круговые диаграммы — своя функция на draw list.
- Спрайты и шрифт берутся из установленного у игрока Майнкрафта во время работы игры (не распространяются,
  CLAUDE.md, «Ассеты»); то, чего в Майнкрафте нет, собирается из тех же примитивов.
- Композицию окон пользователь проверяет по скриншотам.
- Шрифт для будущего UI вне виджетов Майнкрафта — ChakraPetch (`fonts/`, README).
