# Интерфейс

**Сейчас** UI — стоковый Dear ImGui (масштаб шагом 1/8), отладочный. Шрифт — ChakraPetch (решение пользователя:
читаемый и в стиле, в отличие от блочного шрифта названий): Medium для текста, Bold для плашек армий
(`ui/imgui_layer.cpp`, файлы из `fonts/`; без них — Segoe UI). Ниже — решение пользователя, по
которому он переделывается: каркас — в M8, наполнение — в M13 (docs/ROADMAP.md, решение пользователя 28.11.2026); пока
не воплощено.

## UI Майнкрафта на основе Dear ImGui
- ImGui даёт ввод, ID, обрезку, прокрутку, `ListClipper`, тултипы, поля ввода и таблицы. Поверх — свои виджеты
  Майнкрафта через `imgui_internal` (`ButtonBehavior` + `ImDrawList`).
- 9-slice спрайтов `gui/sprites/...` по `.mcmeta`; точечная выборка; целочисленный GUI scale.
- Шрифт — ChakraPetch (`fonts/`) для всего или почти всего текста (решение пользователя: растровый шрифт Майнкрафта
  `font/default.json` мелким кеглем нечитаем); тень текста в духе Майнкрафта — сдвиг на 1 px, цвет × 0.25.
- Панели — процедурно: серый `#C6C6C6`, светлый край сверху-слева, тень `#555555`, чёрный контур.
- Иконки товаров — предметы Майнкрафта, зданий — блоки; флаги стран — баннеры с узорами (данные, не арт).
- Графики — ImPlot; маленькие круговые диаграммы — своя функция на draw list.
- Спрайты берутся из установленного у игрока Майнкрафта во время работы игры (не распространяются, CLAUDE.md,
  «Ассеты»); то, чего в Майнкрафте нет, собирается из тех же примитивов.
- Композицию окон пользователь проверяет по скриншотам.
- Раскладка кода UI — обычный ООП и immediate mode, без DOD и правил детерминизма (UI вне `mc_sim`).

## Как задаётся окно (предложение агента 28.11.2026, ждёт решения пользователя)
Каркас UI — в M8, наполнение — в M13 (docs/ROADMAP.md). Роли — как во всём проекте: пользователь решает «что и где»,
агент — «как».
- **От пользователя — карточка окна словами** (любая форма, хоть список): зачем окно; что показывает (какие числа и
  списки); что в нём можно сделать (кнопки, ползунки — какие команды); откуда открывается (клавиша, клик по
  провинции, флагу, армии); что обязательно сейчас, а что — в M13.
- **Раскладка — по желанию картинкой**: блоки в Paint, фото наброска на бумаге или скриншот EU3/EU4/Майнкрафта с
  пометками — только как образец композиции, их графика не копируется (CLAUDE.md, «Ассеты»). Цветные блоки без
  подписей двусмысленны: лучше прямоугольники с надписью внутри («список полков», «ползунок Treasury»). Картинку —
  в чат или в папку проекта вне git (PNG в репозиторий не идут, `.gitignore`). Без картинки агент сам предлагает
  раскладку, пользователь правит по скриншоту.
- **Порядок работ:** сначала набор виджетов и вкладка-витрина в окне «Dev» (как выглядят панель, кнопка, ползунок,
  вкладки, список, тултип, иконка) — пользователь принимает облик; потом окна по одному на настоящих данных и
  командах; проверка — скриншоты пользователя (агент окно игры не видит), правки — словами или пометками на
  скриншоте.
