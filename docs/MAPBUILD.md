# Сборка карты: исходники и `tools/`

Нужен, только когда трогаешь пайплайн карты. Формат `world.mcmap` — docs/MAPFORMAT.md.

## Исходники (лежат в корне)
Карта — сетка 1152×576 блоков (`WIDTH`, `HEIGHT` в `tools/mapgen/validate_land.py`). Блок — 4×4 пикселя карты
(4608×2304) и куб: ступень по высоте равна ширине блока. Рисунки пользователя — 1 пиксель = 1 блок.

| Файл | Что |
|---|---|
| `heightmap.png` | экспорт Azgaar's Fantasy Map Generator, 4608×2304: в Azgaar Map size и Viewport size 1152×576, вся карта в окне без сдвига, PNG-экспорт ×4, включён только слой высот в монохромной схеме. Единственный источник истины для берегов и высот |
| `land.png` | делает `heightmap.py`, 1152×576: `#000000` море, `#FFFFFF` суша, `#0080FF` озеро (меньше 156 блоков — декоративное: вода на вид, суша в игре). Руками не правится: правка — в Azgaar |
| `wasteland.png` | рисует пользователь: копия `land.png`, пустошь — `#808080`. Связный кусок пустоши — одна провинция без владельца |
| `borders.png` | рисует пользователь: прозрачный фон, линии по суше — `#FF0000` граница земли, `#FFFF00` граница региона (по желанию), `#00FFFF` граница отдельной провинции |
| `biome.png` | рисует пользователь: цвет биома из `data/common/biomes.csv` на каждом блоке суши, пустошь тоже; вода не читается |
| `rivers.png` | рисует пользователь, соглашение EU4 `rivers.bmp` на блоках: прозрачный фон, линии в 1 пиксель по суше; `#00FF00` исток, `#00E1FF` ручей (1 блок), `#0064FF` река (2 блока), `#FF0000` слияние (последний блок притока у реки), `#FFFC00` развилка (пока не поддерживается) |

| `provinces.png/.csv`, `regions.png/.csv`, `adjacency.csv` | делает `generate_provinces.py` в `build/provinces/` (1 пиксель = 1 блок); переносятся в корень руками и **замораживаются**: правки только через `edit_provinces.py`. Названия сгенерированы, их можно править в CSV |
| `fonts/blockyfont.otf` | шрифт названий на карте (`tools/fonts/mapfont.py`): блочный, в духе Майнкрафта; лицензия FontStruct Non-Commercial, в git не идёт |
| `fonts/ChakraPetch-*.ttf` | шрифт UI игры (Medium — текст, Bold — плашки армий; путь — `MC_DEFAULT_FONTS`); в git не идёт |

Сгенерированные таблицы:
- `provinces.csv`: id, color, type (`land`, `wasteland`, `sea`, `lake`), region, region_name, parent (земля), name,
  area (блоков), x, y (центр, блоки), pieces (кусков по 4 соседям), biome (главный биом суши), height (средняя
  ступень суши);
- `regions.csv`: id, color, name, parent (название земли), provinces;
- `adjacency.csv`: a, b, kind (`land-sea` и т. п.), border (длина общей границы в рёбрах блоков).

Бинарники (png, ttf, npz…) в репозиторий не идут.

## Сборка (`tools/`, Python 3.14 + numpy/scipy/scikit-image/Pillow/numba/fontTools)
`bake.py` кладёт в `sys.path` и `tools/mapgen`, и `tools/mapbake`: имена модулей в этих папках не должны совпадать.

Из карты высот:
```bash
python tools/mapgen/heightmap.py                              # heightmap.png -> land.png + build/heightmap/steps.png (ступени)
python tools/mapgen/validate_land.py land.png                 # проверка палитры, связности, тонких мест
python tools/mapgen/validate_land.py wasteland.png --out build/validate_wasteland   # то же для пустошей
python tools/mapgen/border_lines.py                           # проверка borders.png -> build/borders/lands.png
python tools/mapgen/biomes.py                                 # проверка biome.png -> build/biomes/biomes.png
python tools/mapgen/river_paths.py                            # проверка rivers.png -> build/rivers/rivers.png
```
**Линии `borders.png`** (`border_lines.py`). Проходимая суша — суша `land.png` без пустоши `wasteland.png`;
`wasteland.png` вне пустоши обязан совпадать с `land.png`. Земли — куски проходимой суши между красными линиями;
блоки мазка отходят ближайшему куску, так что граница идёт по середине мазка. Кусок меньше 0.1 средней земли
(обрезок) целиком уходит ближайшей земле. Остров (кусок суши с пустошью, где проходимой суши меньше средней земли)
целиком принадлежит одной земле — той, где большая его часть. Оборванный конец — тот, вокруг которого суша по обе
стороны линии соединяется в окне 11×11 блоков. Кусок региона, отрезанный голубой линией, — отдельная провинция;
самый большой кусок региона — остаток, его режет генератор.

**Реки** (`river_paths.py`). Река идёт от истока по линии: шаг к 4 соседям или по диагонали, если оба угловых блока
пусты. Кончается слиянием, первым блоком, касающимся воды стороной, или последним блоком, касающимся воды углом;
исток у озера — сток из озера. Ошибки: развилка или касание другой реки, конец на суше, слияние не у реки, линия, до
которой не дошёл ни один исток, линия на воде. Реки касаются только в слиянии (последние 2 блока притока). Подъём:
блок выше самого низкого блока выше по течению больше чем на 1 ступень (`CARVE`: там, где земля поднимается, русло
врезается на 1 ступень) — его надо перерисовать, иначе нужен каньон.
**Импорт высот** (`heightmap.py`). Azgaar рисует высоту `h` (суша 20–100) серым `d3.interpolateGreys(1 − h/100)`;
импорт обращает эту кривую (точность ±1). Суша — серый от 63; всё темнее — полосы глубин моря и сглаживание берега.
Блок — суша, если суша в большинстве его 4×4 пикселей; его ступень = round((среднее h − 20) / 5), так что h = 100 —
16-я ступень (выше Azgaar не поднимает: там плато). Вода, не доходящая до края карты или меньше `MIN_SEA` = 190 блоков, — озеро (маленькая
вода у края — декоративное озеро, а не морская провинция). Квадрат 2×2, где суша
касается только по диагонали, разрешается сменой блока с самым близким к ничьей голосованием. Импорт отказывается
работать, если размер не тот, картинка не серая или серый суши не ложится на схему (поменяли оформление слоя).
`read_blocks()` отдаёт классы и ступени блоков остальным инструментам; промежуточного файла с высотами нет.

Один раз, когда все исходники проверены:
```bash
python tools/mapgen/generate_provinces.py                     # -> build/provinces/: провинции, регионы, смежность, preview.png, report.txt
```
Результат переносится в корень руками, после этого провинции заморожены.

**Генератор провинций** (`generate_provinces.py`). Земли — из `borders.png`. Каждая земля режется на регионы примерно
по `REGION_PROVINCES` = 8 провинций (жёлтые линии, где есть, режут раньше); кусок меньше половины региона (остров)
уходит ближайшему региону своей земли. На проходимой суше всего `LAND_PROVINCES` = 700 провинций (`border_lines.py`): отрезанные
голубыми линиями — по одной, остаток каждого региона получает провинции по взвешенной площади. Остров никогда не входит
в провинцию на другом массиве суши: такой кусок становится своей провинцией, и резка повторяется с соответственно
меньшим числом клеток, так что острова входят в 700. Кусок провинции, отрезанный фиксированной провинцией, уходит соседу
из своего региона. Вес блока — плотность
провинций: `density` его биома в `data/common/biomes.csv` (тайга 0.6, пустыня 0.5, остальные 1), у берега
провинции-озера до ×`LAKE_DENSITY` = 1.5, сходит на нет за `LAKE_REACH` = 40 блоков; где вес выше, провинции и
регионы мельче. Резка — геодезический Вороной с итерациями Ллойда к взвешенному центру; шаг стоит 1 + шум, каждая ступень
высоты — ещё `STEP_COST`, поэтому границы ложатся на хребты; реки границ не притягивают (решение пользователя). Каждый
связный кусок пустоши — провинция `wasteland`, озеро от 156 блоков — провинция `lake`, декоративное озеро уходит
провинции вокруг. Море — прибрежный пояс (`COAST_BAND` блоков, провинции по `COAST_PROVINCE`) и открытое (по
`OPEN_PROVINCE`). Открытое море уже 36 блоков где угодно (`MIN_OPEN_RADIUS` = 18: полоса между прибрежными водами,
перешеек, кольцо вокруг острова) — прибрежное, так что прибрежные воды не разрезаны океаном; кусок открытого моря меньше
половины `OPEN_PROVINCE` (внутреннее море среди прибрежных вод) — тоже прибрежный. Узкие отростки морской провинции (уже 5 блоков, `SEA_NECK`) уходят соседней, если она есть. Морская провинция —
всегда один связный кусок: лишние куски и провинции меньше `MIN_SEA` = 190 блоков целиком уходят морскому
соседу с самой длинной общей границей; вода без морского соседа остаётся своей провинцией любого размера.
Названия — `names.py`: английские, природа, блоки и мобы
Майнкрафта без Энда и Незера, по биому, высоте и берегу; море — по климату ближайшей суши (у джунглей, саванны и
пустыни — тёплые корни вроде Coral и Turtle, у тайги — холодные вроде Ice и Cod, у остальных — только общие); все уникальны, при том же `SEED` повторяются.

Каждый раз, когда что-то изменилось (провинции и исходники — по блокам, карта в файле — в пикселях карты, блок = 4×4):
```bash
python tools/mapgen/surface.py                                # воксельная поверхность: сводка + build/surface/levels.png
python tools/mapbake/rivers.py                                # реки как ленты в пикселях карты (ничего не пишет)
python tools/fonts/mapfont.py                                 # шрифт названий: метрики Mapfont.fnt + SDF
python tools/labels/provinces.py                              # названия провинций (до positions.py: города их обходят)
python tools/mapbake/positions.py                             # участки домиков, пирсы, точки армий и подписей -> positions.csv
python tools/mapbake/bake.py                                  # build/map/world.mcmap (docs/MAPFORMAT.md); пути марша — marches.py внутри
```
`tools/labels/` нужен `C:\Dev\Projects\eu4\archeologyEU4\Labels\LabelPython` (путь в `tools/labels/reference.py`).

**Город и порт** (`positions.py`). Город провинции — один домик на участке 2×2 блока суши своей провинции (без рек и
озёр): самый ровный участок, из них — с наибольшим простором вдали от границ, воды и букв названия; домик смотрит в
одну из четырёх сторон, разную по провинциям. Пирс есть у каждой сухопутной провинции, граничащей с морской стороной
блока (озёра не считаются): блок берега и два морских блока одной морской провинции подряд, над которыми лежит пирс.
Выбор по порядку важности: открытая вода (слева, справа от пирса и перед ним — море), в стороне от суши соседних
провинций, берег пониже, ближе к городу (решение пользователя: пирс не жмётся к соседу и не идёт вдоль берега).
Морские блоки пирсов не совпадают и не касаются даже углом; первыми выбирают провинции с меньшим выбором.
Точка армии (где стоит фигурка и откуда идёт марш) — никогда не на воде: блок суши, у которого все 8 соседей тоже
суша (без рек, озёр и моря), в глубине провинции и в 10–48 px от города — сразу за домиком, не дальше (решение
пользователя: близость к домику не наказывается); сначала ровная земля — блок, у которого все 8 соседей на его
уровне. Нет такого рядом с городом — такой же блок, но не ровный; ровный где угодно в провинции; любой где угодно;
потом любой сухой пиксель рядом и где угодно, в крайнем случае участок города (`UNIT_TIERS`; `positions.py` пишет, у
каких провинций точка не первого сорта). Реку при выборе точка не учитывает: у 19 провинций она за рекой от домика.
Морская провинция пирса — единственный выход провинции в море (`port_sea`).

**Правка провинций:**
```bash
python tools/mapgen/edit_provinces.py split-islands | give-island X Y NAME | islands-apart | sync-lakes
python tools/mapgen/edit_provinces.py set-region ID "REGION NAME"
```
`set-region`: провинция суши переходит в другой регион (строка `provinces.csv`, её блоки в `regions.png`, счётчики
`regions.csv`); блоки и id не двигаются, `data/setup` не меняется. Острова от `islands-apart` наследуют регион
исходной провинции — если он за морем, переносить так.
`islands-apart`: остров, входящий в провинцию на другом массиве суши, становится своей провинцией (новый id после
последнего, тот же регион, новое название и цвет); номера остальных не меняются.
`sync-lakes`: озеро, у которого в `land.png` стало меньше воды, оставляет себе самый большой кусок; высохшее дно делят
соседи; озеро без воды удаляется, номера после него сдвигаются — и id провинций в `data/setup` переписываются на
новые (docs/GAMEDATA.md, «ссылка на провинцию»). Потом `labels/provinces.py` → `positions.py` → `bake.py`. Названия
правятся в корневых `provinces.csv` и `regions.csv`, затем те же три скрипта. Генератор держать в согласии с правками:
его правила (острова, связность морей) должны давать ту же карту.
