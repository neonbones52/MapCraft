## Папки (C++23, MSVC + CMake/Ninja + vcpkg)
Сборка и запуск — README. Зависимости vcpkg (триплет `x64-windows-static`): `imgui`, `miniz` (jar — это zip), `stb`
(PNG), `nlohmann-json` (`.mcmeta`, биомы).

| Папка | Что |
|---|---|
| `src/core/` | часть симуляции (`mc_sim`): контейнер `world.mcmap` (`map_file`) и его часть для симуляции (`MapData`: провинции, регионы, соседи, точки, имена), CSV, лог, `det_math.h` (математика и MXCSR симуляции), `fixed.h` (фиксточка ×1000 модификаторов и боя), `random.h` (счётный генератор `random(seed, день, сущность, назначение)`); без вида, платформы и игры |
| `src/view/` | вид: ввод, камера, раскладка названий EU4 (`labels.cpp`), темп времени `pace.h`, вся карта для вида `MapView` (`MapData` + пиксели, блоки, границы, реки, шрифт, названия); правила детерминизма на него не распространяются |
| `src/minecraft/` | ассеты из jar Майнкрафта игрока: zip, PNG (и PNG с диска — флаги), `.mcmeta`, ванильные биомы, цветовые карты, NBT-структуры, блочные модели, рост деревьев, меши из блоков, модели сущностей с позами (`entity_models`: солдат в железе, конь, полевая пушка из блочных текстур); где искать jar |
| `src/render/` | D3D11: карта (блоки `terrain`, модели `models`, фигурки армий `figures`, границы, названия) |
| `src/game/` | симуляция (`mc_sim`, строго детерминирована) без вида, UI и D3D. `GameData` = `Content` (неизменяемые справочники, все строки) + `WorldState` (SoA-столбцы) + `Cache` (суммы модификаторов). `World` владеет ими и отдаёт наружу только `const`; мир продвигает только `World::advance_days`, команды игроков — очередь `commands.h` (`World::post`, `run_commands`). `Session` — выбор страны, потом игрок. `calendar.h` — календарь. `countries.cpp` — запросы по странам. `armies.h` — слоты армий, полков и генералов (взять, освободить, ссылка слот + поколение). `movement.h` — марш армий: граф переходов, путь, день марша. `modifiers.h` — суммы модификаторов стран и формулы над ними. `combat.h` — бой: день боёв после марша над `Battle` (линии и резерв), рабочие данные дня. `recovery.h` — восстановление армий вне боя на месячном тике (мораль; люди — M8). `war.h` — войны: объявление, кэш «кто с кем воюет». `occupation.h` — осада и оккупация: день осад после боёв, фазы и сдача, гарнизоны на месячном тике, контролёр провинции. `economy/ledger` — единственный, кто пишет деньги (фаз экономики пока нет) |
| `src/ui/` | интерфейс игры на Dear ImGui (ввод из `mc::Input`): слой ImGui, флаги, виджеты, экраны `screens/` (выбор страны, HUD, время, подсказка провинции, плашки армий) |
| `src/app/` | `App` — карта: камера, режимы карты (`map_modes.cpp`), облик блоков (`terrain_look.cpp`, таблица биомов `biome_table.cpp`), домики, пирсы и деревья (`scenery.cpp`), фигурки армий, их марш и ходьба, точки плашек (`army_figures.cpp`), пикинг, отрисовка. `army_orders.cpp` — выбор своих армий и приказы мышью (команды). `bindings.cpp` — все привязки клавиш. `Shell` — игра для хоста, связывает `World`, `App`, `Session`, `Pace`, `ArmyOrders` и `GameUi` |
| `src/host/win32/` | платформа: общие для обоих exe окно и ввод (`window`), D3D11 и swap chain (`d3d_target`), лог рядом с exe (`log_file`) — библиотека `mc_host_win32`; `main.cpp` — хост `mapcraft.exe` |
| `src/headless/` | `mapcraft_sim.exe` — только `mc_sim`: сценарий (`scenario`), прогон без окна, контрольная сумма и дамп (`snapshot`), папка прогона (`run_record`) |
| `src/editor/` | `mapcraft_editor`: `App` + свой `GameData` (правит старт, а не живой мир) + панели ImGui; окно — из `host/win32` |

Граф слоёв (кто кого включает и где какие библиотеки) проверяет `tools/lint/layers.py` первым шагом каждой сборки;
таблица графа — в самом `layers.py`.

Библиотеки: `mc_sim` — `core/` и `game/` (флаги детерминизма, линтер `tools/lint/sim_lint.py` первым шагом сборки);
`mc_game` — всё остальное, линкует `mc_sim`; `mapcraft_sim` линкует только `mc_sim`.

Правила слоёв:
- `game/` и `core/` не знают вида, UI и D3D; `WorldState` меняют только правила самого `World`.
- Экраны `ui/` только читают состояние и возвращают `UiCommands`; выполняет их `Shell`.
- `App` и `Camera` не знают клавиш: им приходят намерения (`CameraInput`), коды клавиш игры есть только в
  `app/bindings.cpp` (у редактора — свои, Ctrl+S/Z/Y и Esc, через ImGui в `editor/`, мимо `bindings.cpp`: инструменту
  можно).
- В `Shell` объект `World` объявлен раньше `App`, потому что карта держит указатель на его данные.

## Отладочное (`DevOptions`)
Отладочное в exe разрешено в рамке (CLAUDE.md, «Как работать»), чтобы флаги и их разбор не расползались по коду
(решение пользователя: в Tamriel Universalis флаги и их разбор съели половину кода):
- все переключатели — поля одной структуры `DevOptions` (`app/dev_options.h`); меняются только в окне «Dev» по **F9**,
  окно строится по структуре (галочка на `bool`, ползунок на число), сохраняется одним файлом целиком. Флагов
  командной строки под отладку нет (кроме `mapcraft_editor --check`);
- отладочное только показывает (оверлеи, окна, графики, режимы рендера) и не меняет правила игры; в `mc_sim`
  переключателей нет; действия отладки — обычные команды, как у игрока;
- не больше ~15 переключателей, каждый — строкой ниже; в конце среза просроченные удаляются.

Окно «Dev» (`ui/screens/dev_window.h`, F9 — `app/bindings.h`, только когда игрок играет) пока без переключателей —
`DevOptions` и его файл появятся с первым из них. В окне — действия как команды игрока: список войн и «Declare war» на
каждую другую страну (команда `declare_war`, docs/GAMEDATA.md, «Война»; до настоящего UI, M13).

## Известные долги
- **LNK1235 «corrupt or invalid COFF symbol table» у `mc_game.lib`** (дважды 26.11.2026, обе — при пересборке
  `mc_sim` и `mc_game` разом): причина не найдена. Параллельная линковка двух exe — не причина: в графе Ninja оба exe
  ждут готовый lib и только читают его; семь пересборок в тех же условиях ошибку не дали — она случайная. Версии: lib
  на диске битый (тогда — `mc_game`/`mc_sim` как OBJECT-библиотеки CMake, без архива) или свежий файл трогал внешний
  процесс; 26.11.2026 пользователь добавил `C:\Dev` в исключения Defender — повторится, значит не Defender. Что
  делать при повторе — CLAUDE.md, «Окружение». 28.11.2026 — ещё дважды, оба раза при линковке `mapcraft_editor.exe`
  (сначала на `mc_sim.lib`, потом на `mc_game.lib`, в обоих случаях `mapcraft.exe` с той же lib слинковался): копия lib
  читается (`lib /list`, `dumpbin /linkermember`), повтор сборки без изменений проходит, хеш `mc_game.lib` до и после
  повтора совпадает — значит, lib на диске цел, сбой — при чтении во время линковки. В тот же день ещё дважды — при
  линковке `mapcraft.exe` и снова редактора (`mc_game.lib`), с тем же итогом: повтор проходит, хеш тот же.
