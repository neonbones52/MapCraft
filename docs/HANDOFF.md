# Передача: откуда проект и что дальше

Документ для нового агента в этом репозитории. Остальные документы описывают текущее состояние; здесь — происхождение,
решения пользователя и открытые вопросы. Закрытый вопрос отсюда убирается, а решение переносится в нужный документ.

## Происхождение
MapCraft выделен из **Tamriel Universalis** (TU, github.com/neonbones52/TamrielUniversalis; локальной копии
нет). TU — EU4-подобная стратегия по Тамриэлю: SKSE-плагин для Skyrim AE со
входом через главное меню, плюс `tu_dev.exe` и `tu_editor.exe`. Истории TU в git MapCraft нет: репозиторий новый
(github.com/neonbones52/MapCraft).

Перенесено и переименовано (`tu` → `mc`, `tu_dev` → `mapcraft`, `tu_editor` → `mapcraft_editor`, `tamriel.tump` →
`world.mcmap`, magic `TUMP` → `MCMP`):
- весь C++ кроме хоста SKSE: ядро, камера, CSV, перенос алгоритма названий EU4, рендер границ, рек и названий,
  режимы карты, пикинг, `GameData`/`World`/`Session`/`Pace`, отладочный UI на ImGui, редактор провинций, хост Win32;
- Python-конвейер карты, не зависящий от вида: генерация и правка провинций, реки, границы, точки провинций,
  шрифт и названия, упаковка. С тех пор он переведён на сетку блоков, а ручная суша (импорт контурной карты)
  удалена: суша идёт из карты высот.

Вырезано:
- **Скайрим:** хост SKSE (хуки, кнопка в меню, сон Скайрима, звук через движок), overlay-порт CommonLibSSE-NG,
  реверс Скайрима (`tools/re`), деплой в папку Скайрима.
- **TES:** все данные (`data/`, провинции, регионы, имена, подписи с фан-карты, пулы имён), раздача имён
  (`tools/names`), дозаполнение данных (`tools/data`), календарь TES, Blender-модели домов культур, Blender-рамки UI.
- **Вид гладкой карты** (решение пользователя: карта будет воксельной): рельеф из эскиза (`heightmap.py`), биомы,
  CC0-текстуры и слои материалов, снег, вода с рябью и уровнями озёр, LOD рельефа, деревья и дома из glb, стол с
  рамой, свой курсор игры. Из формата ушли `HGHT HPAR WBOD WLVL SURF CMAP TMAT MDIF MNRM DECO DDIF DNRM T* C* CUR*`;
  в `RVTX` больше нет уровня воды.

Вместо них — свой рендер блоков (docs/RENDER.md) и упрощённый `positions.py` (без моделей: порт есть у каждой прибрежной
провинции). Если понадобится что-то из вырезанного, смотреть в TU как справку; переносить только по решению
пользователя.

## Решения пользователя (из разговора о старте MapCraft)
- Жанр: смесь EU4 и Victoria 2. От Victoria 2 — POPs в первую очередь и экономика с товарами, RGO, заводами;
  в остальном упор на EU4. DOD: SoA, SIMD.
- Сеттинг Майнкрафта, фанатский и некоммерческий. UI и звуки — Майнкрафта.
- **UI делается кодом**, 1 в 1 как в Майнкрафте: спрайты из jar игрока (`gui/sprites/...` с `.mcmeta` nine-slice),
  растровый шрифт (`font/default.json`, есть кириллица), тень текста — сдвиг на 1 px и цвет × 0.25, целочисленный GUI
  scale. Панели — процедурно (серый `#C6C6C6`, светлый край сверху-слева, тень `#555555`, чёрный контур). Иконки
  товаров — предметы Майнкрафта, зданий — блоки; флаги стран — баннеры с узорами (данные, не арт). Чего в Майнкрафте
  нет (диаграммы POPs, графики цен), собирается из тех же примитивов. Вместо стилизации ImGui — свой UI-слой.
- **Ассеты Майнкрафта не распространяются**: игра читает их из `.minecraft` игрока. Звуку понадобится свой модуль
  (XAudio2 или miniaudio, декодирование ogg); прежний звук шёл через Скайрим и вырезан.
- **Карта воксельная**: кубики, а не плавный рельеф; деревья — настоящие майнкрафтовские (дуб, берёза, ель,
  джунгли…) как декор. Исходники — PNG оговорённого формата от пользователя, прогоняются через `tools/`, как в TU.
- Весь код пишет агент.

## Где остановились (14.11.2026)
Конвейер карты на сетке блоков сделан и прогнан, провинции утверждены, игра рисует карту блоками (docs/RENDER.md).
- **Исходники** нарисованы пользователем и проверены: `heightmap.png` (экспорт Azgaar, утверждён 13.11 вместе с
  плато ~1400 блоков и сушей у верхнего края), `wasteland.png`, `borders.png` (18 земель, 23 «центра силы» —
  отдельные провинции, плотное ядро у большого озера — «местная Германия»), `biome.png`, `rivers.png` (40 рек).
  Контракт файлов и цветов — README «Карта: исходники»; как их читают инструменты — README «Карта: сборка».
- **Провинции** (`generate_provinces.py` → перенесены в корень, заморожены): 107 регионов, 867 провинций суши
  (850 + 17 островов, отделённых `edit_provinces.py islands-apart`), 6 пустошей, 1 озеро, 173 моря — всего 1047.
  Плотность: тайга и пустыня реже, у озера чаще (`density` в `data/common/biomes.csv`). Названия сгенерированы.
  **Нарезка утверждена пользователем 14.11.2026**: номера провинций — ключ для будущих данных. Если всё же понадобится
  правка — только `edit_provinces.py` (новая команда при нужде), затем `labels/provinces.py` → `positions.py` →
  `bake.py`. Генератор держать в согласии с правками (правило островов есть и там).
- **`world.mcmap` версии 2** собран (docs/MAPFORMAT.md): карта в пикселях (блок = 4×4), секции блоков `B*` (класс с
  реками, уровни земли и воды, биом), тип провинции `wasteland` (игра: суша без хозяина, непроходима для названий,
  граница с ней — как граница страны), границы суши по краям блоков, шрифт названий `blockyfont.otf`.
- **Рендер блоков** сделан: загрузчик jar `src/minecraft/`, облик `app/terrain_look.cpp` по
  колонкам `data/common/biomes.csv` (стартовый набор блоков сделал агент, правит пользователь), `render/terrain.cpp`.
  Собрано без предупреждений, шейдеры проходят `fxc`; **в игре агент его не запускал и не видел** — вид проверяет
  пользователь. Пользователь: «выглядит отлично». По его замечаниям: ступени рек — водопады (текущая вода, без щелей
  на ступенях в 2+ блока), река нигде не выше берега (`surface.py`). Названия: максимум под буквами «слишком
  выпирал» — теперь плоскость на медиане верхов под буквами. Скрытие: пользователь хочет, чтобы надпись своей
  провинции была видна целиком, а надпись за чужой грядой обрезалась (вариант «прятать за любыми блоками» резал и
  тряс буквы); теперь прячут только блоки чужой группы — пользователь: «этап практически отшлифован». Временное до слоёв EU4 на блоках:
  границы подняты на верх блоков в вершинном шейдере.
  Данных игры (`data/setup`) пока нет.

## Решения по виду карты, ещё не реализованные
- **Деревья** — настоящие майнкрафтовские по биому (дуб, берёза, ель, джунгли…), как декор; оттенок листвы — из
  `colormap/foliage.png` и `foliage_color` биома (как трава); колонки деревьев — в `biomes.csv`.
- **Политическая заливка** одинаково плотная на любом зуме, как в EU4; режим по умолчанию — политический; остальные
  режимы (RGO, население…) — потом, кнопками справа снизу над миникартой.
- **Дальний вид** как Distant Horizons: вдали рельеф можно упрощать в разумных пределах; LOD — по реверсу EU4
  (`archeologyEU4/Render/HEIGHTMAP.md`; Ghidra-мост с eu4.exe и полным pdb — `http://127.0.0.1:8089/`, пользователь
  держит его открытым; запросы как в `archeologyEU4/UtilityAI/tools/evidence_tools.py`).
- **Путь к jar** выбирается игроком (экран настроек, когда будет); пока — поиск по двум путям (docs/RENDER.md,
  «Облик блоков»).
- **Логический terrain провинции** выводится из биома и высот (в `provinces.csv` уже есть `biome` и `height`), в
  редакторе меняется. Отложен пользователем до заполнения игровых данных: тогда же решается, какие RGO, по каким
  правилам и как инструмент раскладывает их по провинциям.

## Порядок работ (каждый шаг — по просьбе пользователя)
1. Правки вида блоков по замечаниям пользователя (блоки в `biomes.csv`, свет, туман, вода). Открыто: мерцание
   (горизонтальные полосы) на боках обрывов на границе провинций суши с пустошью, видно и в режиме рельефа без
   заливки (скриншот пользователя 14.11: обрыв гор Gravel Spires над зелёной провинцией) — причина ещё не найдена.
2. Дальний вид (LOD).
3. Слои EU4 на блоках: заливка, границы по краям блоков, названия поверх рельефа.
4. Деревья по биомам.
5. Логический terrain — вместе с игровыми данными (RGO и правила раскладки).
