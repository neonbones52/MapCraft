# Формат карты `world.mcmap` (версия 2)

Собирается `tools/mapbake/bake.py` из исходников карты (`heightmap.png`, `wasteland.png`, `biome.png`, `rivers.png`),
замороженных `provinces.png/.csv`, `regions.csv`, `adjacency.csv`, из `positions.csv` и того, что приготовили остальные
инструменты (`build/`): шрифт (`tools/fonts/`) и названия провинций (`tools/labels/`). Исходники — на сетке блоков;
карта в файле — в пикселях карты, блок = `BLOCK` × `BLOCK` пикселей (4). Порядок сборки — README. Читает `core/map_data.cpp` (`MapData`), все массивы — `std::span` в
загруженный файл.

Все числа little-endian. Массивы по провинциям имеют длину `n` = число провинций + 1: индекс 0 означает «нет провинции».

## Заголовок (24 байта) и таблица секций

| Поле | Тип | |
|---|---|---|
| magic | char[4] | `MCMP` |
| version | u32 | 2 |
| width, height | u32, u32 | пиксели карты (4608 × 2304) |
| n | u32 | провинций + 1 |
| sections | u32 | число записей в таблице |

Сразу за заголовком идёт таблица: `sections` записей по 16 байт — `tag char[4]`, `size u32`, `offset u64` (от начала
файла, выровнен на 16). Загрузчик проверяет размеры всех секций и отказывает с подсказкой пересобрать `bake.py`.

## Секции

| Тег | Тип | Содержимое |
|---|---|---|
| `PIDM` | u16[w·h] | ID провинции на пиксель, строки сверху вниз |
| `CLAS` | u8[w·h] | класс пикселя из `land.png`: 0 море, 1 суша, 2 озеро (в т.ч. декоративное), 3 пустошь |
| `PTYP` | u8[n] | 0 нет, 1 суша, 2 море, 3 озеро, 4 пустошь |
| `PREG` | u16[n] | индекс региона (1-based, 0 = нет) |
| `PCOL` | u32[n] | отладочный цвет RGBA8 (цвет провинции в `provinces.png`) |
| `PPOS` | f32[n·8] | город xy, армия xy, подпись xy, порт xy (пиксели карты; NaN = нет; порт — точка над морем, где стоят корабли) |
| `PPSE` | u16[n] | морская провинция порта |
| `PPRO` | f32[n] | направление порта от суши к морю, радианы, x вправо / y вниз |
| `ADJO` | u32[n+1] | CSR: соседи провинции `i` — `ADJI[ADJO[i] .. ADJO[i+1])` |
| `ADJI` | u16[m] | ID соседей |
| `ADJL` | u16[m] | длина общей границы, px (рёбра блоков × 4) |
| `PNAM` | u32[n+1] + UTF-8 | имена провинций: строка `i` = `blob[off[i] .. off[i+1])` |
| `RNAM` | то же | имена регионов, 1-based |
| `RPAR` | u8[regions+1] | земля региона (его `parent` в `regions.csv`) → индекс в `LNAM` |
| `LNAM` | то же | имена земель |
| `BVTX` | f32[m·2] | точки ломаных границ (x, y в пикселях карты, углы пикселей — целые координаты) |
| `BSEG` | u32[k·4] | цепочки границ: первая точка, число точек, `a \| b << 16` (a < b), флаги (1 — замкнута) |
| `FPAR` | i32[8] | шрифт названий: lineHeight, base, padding, texels атласа на px метрики, запас текселей, ширина и высота атласа, SDF spread (текселей) |
| `FCHR` | i32[c·12] | символ: код cp1252, x, y ячейки атласа, ширина и высота ячейки, xoffset, yoffset, width, height, xadvance (семантика Mapfont.fnt, layout-quad с padding), x, y quad'а в ячейке (текселей) |
| `FKRN` | i32[k·3] | кернинг: first, second, amount |
| `FATL` | u8[w·h] | SDF-атлас глифов: 0.5 — край чернил, spread текселей на весь диапазон |
| `NGLY` | f32[g·7] | запечённые названия провинций (`build/labels/province_names.npz`): x, y (px карты), направление чтения x, y, ширина и высота quad'а (px карты), код cp1252 |
| `RVTX` | f32[p·3] | точки рек через ~1 px от истока к устью: x, y, ширина воды (px карты); пусто без `rivers.png` |
| `BDIM` | u32[4] | сетка блоков: ширина, высота, пикселей карты на сторону блока, число строк `BKEY` |
| `BCLS` | u8[bw·bh] | класс блока: 0 море, 1 суша, 2 озеро, 3 пустошь, 4 река |
| `BHGT` | u8[bw·bh] | уровень верха земли, блоков от дна моря: суша ступени s — s + 2; под рекой и озером — дно (вода − 1); море — 0 |
| `BWTR` | u8[bw·bh] | уровень верха воды: море 1, озеро и река — свой уровень, суша — 0 (воды нет) |
| `BBIO` | u8[bw·bh] | биом блока — индекс в `BKEY`, 0 на воде |
| `BKEY` | u32[k+1] + UTF-8 | ключи биомов `data/common/biomes.csv` в порядке строк, `[0]` = '' |
| `RSEG` | u32[r·4] | реки: первая точка, число точек, флаги (1 — исток на суше: сужается к нему, 2 — впадает в реку, 4 — в море/озеро), индекс реки, в которую впадает (`0xFFFFFFFF` — нет) |

Движок пока не читает `ADJL`, `PPSE`, `PPRO` (понадобятся симуляции: длина границ, порты); `RPAR`/`LNAM` (земли) идут в
названия стран. Декоративные озёра: `CLAS == 2`, но `PIDM` указывает на сухопутную провинцию, т.е. вода рисуется, а
геймплейно это суша.

Секции блоков — воксельная поверхность (`tools/mapgen/surface.py`): уровни считаются в блоках от дна моря; верх моря
— 1, суша ступени 0 — на блок выше. Река стоит на блок ниже самого низкого берега выше по течению (ручей — 1 блок,
река — 2: второй блок сбоку от пути, на более низкой стороне; диагональный шаг пути заполняет нижний угловой блок).
Озеро — на блок ниже самого низкого берега. Под водой моря ничего не рисуется. Движок пока не рисует блоки: секции
читает `MapData`, рендер блоков — следующий шаг (docs/HANDOFF.md).

## Откуда данные
- **Границы** (`tools/mapbake/borders.py`): контуры по рёбрам пикселей между узлами, где сходятся ≥ 3 провинции, точки
  — середины рёбер. Граница, касающаяся суши, не сглаживается: идёт по краям блоков; между двумя водными провинциями
  — скользящее среднее как EU4 `SmoothBorders`. Затем упрощение Дугласа — Пекера. Есть и берега (суша — вода): рендер решает сам, какие цепочки рисовать.
- **Реки** (`tools/mapbake/rivers.py`): пути по блокам из `tools/mapgen/river_paths.py` через центры блоков, устье — на
  кромке воды, сток озера — от его берега, приток — до реки, в которую впадает; линия сглаживается. Ширина воды — по
  блокам: ручей 4 px, река 8 px.
- **Точки** (`tools/mapbake/positions.py`): город — самая глубокая точка главного куска провинции вдали от границ, воды,
  рек и букв её названия (если хватает места); армия — в 22–48 px от города; подпись — самая глубокая точка; порт —
  у каждой сухопутной провинции с морским соседом.
- **Названия провинций** (`tools/labels/provinces.py`): алгоритм EU4 (через LabelPython), каждая провинция — своя
  группа. Суша — ровно как EU4; моря и озёра ниже по иерархии: не касаются суши и других надписей (зазор
  `WATER_PAD` 2 px), отступ от берега растёт, буквы уменьшаются; если не влезает при `WATER_MIN_SCALE`, вода остаётся
  без названия.
- **Шрифт** (`tools/fonts/mapfont.py`): `blockyfont.otf` в метриках Mapfont.fnt, SDF-атлас; знаков, которых нет в шрифте,
  в атласе нет (в названиях только буквы и пробелы). Q, Ç и J берут layout box
  буквы без хвоста (Q = O), чтобы хвост не сдвигал букву с кривой.

| Скрипт | Что делает |
|---|---|
| `mapgen/heightmap.py` | `heightmap.png` → `land.png`; классы и ступени блоков для остальных скриптов (`read_blocks`) |
| `mapgen/validate_land.py` | проверка `land.png` (и `wasteland.png`: та же палитра плюс пустошь) |
| `mapgen/border_lines.py` | чтение и проверка `borders.png`: земли, оборванные концы линий, отдельные провинции; превью `build/borders/lands.png` |
| `mapgen/biomes.py` | чтение и проверка `biome.png` по цветам `data/common/biomes.csv`; превью `build/biomes/biomes.png` |
| `mapgen/river_paths.py` | реки `rivers.png` как пути по блокам: истоки, устья, слияния, ошибки, подъёмы; превью `build/rivers/rivers.png` |
| `mapgen/generate_provinces.py` | регионы, провинции суши, пустоши, озёра и моря на сетке блоков, названия → `build/provinces/` |
| `mapgen/names.py` | генератор названий в духе Майнкрафта |
| `mapgen/palette.py` | различимые цвета для карт с метками |
| `mapgen/edit_provinces.py` | правки замороженной карты |
| `mapgen/sources.py` | общее чтение CSV, провинций (по блокам и в пикселях карты) и классов блоков с пустошью |
| `mapgen/surface.py` | воксельная поверхность по блокам: классы с реками, уровни земли и воды, биомы (секции `B*`) |
